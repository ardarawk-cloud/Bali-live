# Bali Live

24H interactive TikTok LIVE visual layer for Arda.

## Current features
- Bali time clock (Asia/Makassar)
- Automatic daypart themes:
  - 00:00–04:59 — Bali Midnight
  - 05:00–10:59 — Bali Morning
  - 11:00–15:59 — Bali Day Vibes
  - 16:00–18:29 — Bali Golden Hour
  - 18:30–23:59 — Bali After Dark
- Animated ambient background, rain and equalizer
- Song request instructions for TikFinity / Spotify
- Automatic version checking every 30 seconds so future repo updates can refresh the LIVE page

## Planned
- TikFinity event bridge
- AI chat commands such as !curhat and !tanya
- Gift-priority interactions
- Now Playing / queue integration
